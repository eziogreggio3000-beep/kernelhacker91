# KERNEL HACKER '91 · versione PC

App per Windows, Mac e Linux costruita con Electron. Il gioco è `game/index.html`.

- **F11**: schermo intero
- **F9**: modalità striscia (la finestra diventa una barra in basso, sempre sopra le altre)
- I salvataggi restano sul computer, nella cartella dati dell'app.

Ogni modifica in `desktop/` fa partire GitHub Actions, che pubblica i file nella release **pc**.
